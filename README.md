## 🔬 Key Projects

### 01. c-ALD Growth Process Optimization

CdSe nanoplatelet 성장 과정에서 공정 조건을 조절하며 목표 두께와 균일도를 확보하는 연구를 수행했습니다.

**주요 경험**

* 성장 공정 조건 최적화
* 공정 조건과 구조/광학 특성 비교
* TEM 및 분광 분석을 활용한 결과 검증
* 4 ML → 6 ML 성장 공정 최적화
* 공정 개선을 통한 균일도 약 **75% 향상**

**Process Engineering Point**

공정 조건을 변경한 뒤 단일 결과만 확인하는 것이 아니라 여러 계측 데이터를 함께 비교하여 공정 변화의 영향을 검증했습니다.

---

### 02. Ligand-Shell Engineering

CdSe nanoplatelet의 표면 리간드 조성을 제어하여 입자 간 상호작용과 분산 안정성의 관계를 분석했습니다.

Oleate와 acetate의 비율을 단계적으로 변화시킨 샘플을 제작하고, 각 조건에서 나타나는 물성 변화를 비교했습니다.

**주요 분석**

* UV–Vis
* PL / TRPL
* TEM / SEM
* DLS
* ζ-potential
* FTIR
* SAXS

**Process Engineering Point**

한 개의 공정 변수를 체계적으로 변화시키고 다른 조건을 최대한 고정하여 영향도를 확인하는 DOE 기반 사고방식을 경험했습니다.

또한 여러 계측 결과를 교차 검증하여 관찰된 현상의 원인을 단계적으로 좁혔습니다.

---

### 03. Semiconductor Process Data Analysis

반도체 공정 데이터를 활용하여 Lot/Wafer 단위 수율 이상과 공정 변수의 관계를 분석했습니다.

**분석 데이터**

* Yield
* ET (DC)
* ADI / ACI CD
* Thickness
* FDC

**주요 분석**

* Lot/Wafer 기준 데이터 전처리 및 결합
* 저수율 Lot 탐색
* 설비 및 Chamber 이력 비교
* 공정 Step별 데이터 분석
* Trend 분석
* Correlation 분석
* p-value 기반 통계적 관계 확인

**사용 Tool**

`Python` `Spotfire` `Excel`

**Process Engineering Point**

단순히 상관계수가 높은 변수를 원인으로 판단하지 않고,

**수율 이상 → Lot 확인 → 공정 이력 → 설비/Chamber → 계측값**

순서로 데이터를 연결하여 실제 공정 원인 후보를 좁히는 방식으로 분석했습니다.

## 🎯 Engineering Philosophy

> 공정 이상을 단순한 결과로 보는 것이 아니라
> **공정 조건, 설비 이력, 계측 결과, 수율 데이터를 연결하여 원인을 찾는 엔지니어**가 되고 싶습니다.
